## 为什么选择 Next.js？

在众多前端框架中，Next.js 以其**混合渲染策略**、**出色的性能优化**和**庞大的生态**脱颖而出。对于个人博客来说，它提供了完美的平衡：

- **SSG (静态生成)**：首页、归档等不变的页面在构建时生成，访问速度极快
- **ISR (增量静态再生)**：文章页面支持按需更新，无需重新构建整个站点
- **App Router**：基于 React Server Components，减少客户端 JavaScript 体积
- **内置优化**：图片优化、字体加载、元数据管理开箱即用

## 项目结构设计

一个清晰的项目结构是可维护性的基础：

```
src/
├── app/              # App Router 页面
│   ├── [locale]/     # 双语路由
│   │   ├── blog/     # 博客页面
│   │   ├── archive/  # 归档
│   │   └── about/    # 关于我
│   └── layout.tsx    # 根布局
├── components/       # 可复用组件
├── lib/              # 工具函数
│   ├── posts.ts      # 内容处理
│   ├── i18n.ts       # 国际化
│   └── config.ts     # 站点配置
content/
├── posts/
│   ├── zh/           # 中文文章
│   └── en/           # 英文文章
```

## 核心技术选型

### MDX：让 Markdown 更强大

MDX 允许你在 Markdown 中直接使用 React 组件，这意味着你可以：

- 在文章中嵌入**交互式组件**（如代码演示、图表）
- 使用**自定义 Callout 组件**来突出重要信息
- 复用整个组件库来丰富文章表现力

### Tailwind CSS：快速构建一致的 UI

使用 Tailwind 的 utility classes，可以快速实现设计系统中的间距、颜色和排版规范，同时保持代码的简洁性。

## 性能优化要点

> 好的性能不是优化出来的，而是设计出来的。

- 使用 `<Image />` 组件自动优化图片（WebP/AVIF 格式、响应式尺寸）
- 使用 `next/font` 自托管字体，避免外部网络请求
- 利用 ISR 缓存策略，平衡内容时效性和访问速度
- 关键路径渲染优先，非关键内容延迟加载
